# BG_Paint - Simple Drawing and Erasing Tool

BG_Paint is a simple drawing and erasing tool created using Python's Tkinter library. It allows the user to draw on a canvas with a pencil tool and erase with a circular eraser tool. The user can choose the pen size and eraser size and also select the drawing color from a predefined list or pick a custom color using a color picker dialog.

## Features

1. **Drawing and Erasing**: The application supports two main tools, "Draw" and "Erase." When the "Draw" tool is selected, left-clicking on the canvas allows the user to draw with a pencil tool. When the "Erase" tool is selected, right-clicking on the canvas allows the user to erase with a circular eraser tool.

2. **Pen and Eraser Size**: The user can change the size of the pen and eraser using the "Size" menu. There are options to increase and decrease both the pen size and eraser size.

3. **Color Selection**: The user can choose the drawing color from a predefined list of colors. The available colors are black, red, green, blue, and yellow. Additionally, there is an option to pick a custom color using a color picker dialog.

## How to Use

1. Run the Python script, and the application window will appear.

2. The default tool is set to "Draw." To switch to the "Erase" tool, go to the "Tools" menu and select "Erase."

3. To draw, left-click on the canvas and drag the mouse to create lines or shapes.

4. To erase, right-click on the canvas and drag the mouse to erase parts of the drawing.

5. To change the pen size or eraser size, go to the "Size" menu and choose the desired options.

6. To change the drawing color, use the color picker dropdown to select one of the predefined colors.

7. To pick a custom color, click on the "Pick Custom Color" button. A color picker dialog will appear, allowing you to choose a color.

8. To clear the canvas, close the application and restart it.

## Dependencies

- Python 3.x
- Tkinter Library

## Compatibility

The application should work on any platform that supports Python and Tkinter.

## Code Explanation

The code uses Python's Tkinter library to create the graphical user interface. It defines various functions to handle drawing, erasing, color selection, and size changes. The canvas is the primary drawing area, and the application uses event bindings to capture mouse actions.

This application is intended for educational purposes and as a basic demonstration of using Tkinter for drawing and erasing functionalities. For more complex or feature-rich drawing applications, additional functionalities and improvements would be required.
